# Mission: Product Thinking (IDG, Singapore Government)

## Why
General upskilling: build a solid, practical grounding in product thinking as taught by the Institute of Digital Government (IDG), so that when faced with a fuzzy request ("we need an app / an AI tool for X") the user can think clearly about the problem before anyone builds anything.

## Success looks like
- Given a vague public-service case, can separate the *problem* from the proposed *solution*.
- Can write one sharp, data-backed problem statement using IDG's 4Cs (Clarity, Consequence, Cause, Confirmation).
- Can run a Five Whys to get from symptom to root cause.
- Can tell outputs from outcomes, and pick metrics that measure the change achieved.
- Can list the riskiest assumptions behind a proposed solution and how to test them.
- Can explain the idea of Policy–Ops–Tech integration and customer experience in their own words.

## Constraints
- No prior product / design / metrics experience — start from zero, define every term.
- No real project to practise on — use realistic public-service case studies.
- Short lessons; one tangible win each.

## Out of scope (for now)
- Hands-on AI/ML engineering, delivery methods (Scrum etc.), UI design craft.
